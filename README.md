## 📝 Note style

- Giải thích chính bằng **tiếng Việt**.
- Giữ nguyên các từ thực chiến như `open`, `closed`, `filtered`, `open|filtered`, `SYN`, `RST`, `Nothing`, `timeout`, `-sV`, `-sS`.
- Tập trung vào **mental model** và **evidence**, không chỉ học thuộc command.
- Chỉ ghi lại nội dung ngắn gọn đủ để review nhanh.
